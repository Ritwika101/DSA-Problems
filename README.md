# DSA Problems

A curated collection of **290+ C++ solutions** to Data Structures and Algorithms problems across core DSA topics.

The repository is designed especially for students who are beginning DSA and want a practical reference for **what problems to solve while learning each topic**.

## Topics Covered

- Dynamic Programming
- Graphs
- Trees
- Binary Search
- Heaps
- Hashing
- Prefix Sum and Sliding Window
- Recursion & Backtracking
- Stacks
- Two Pointers
- Bit Manipulation

## Platforms

Problems in this repository are sourced from platforms such as:

- LeetCode
- GeeksforGeeks
- Coding Ninjas
- LintCode
- SPOJ

## Purpose

This repository aims to help students starting with Data Structures and Algorithms by providing a structured set of practice problems across important topics.

It can be used as a reference for:

- identifying useful problems to solve while learning DSA
- practicing common algorithmic patterns
- comparing approaches through C++ implementations
- revising core concepts before interviews or coding assessments
